Site Malicioso

ATENÇÃO: Esta página simula um ataque CSRF. Ela força o navegador do usuário logado a transferir dinheiro sem que ele perceba.

Como funciona o ataque:

  1. O usuário faz login na aplicação vulnerável (http://localhost:8080)
  2. O usuário visita ESTE site malicioso (ou recebe um email com link)
  3. Este site submete um formulário automaticamente para /transferir
  4. O navegador envia os cookies de sessão automaticamente
  5. A transferência é executada sem consentimento do usuário!
